# Escapement 设计文档

> 状态：第一版。规则和关卡已由测试验证，**还没有真人试玩**。“玩家会怎么想”都是假设，见第 7 节。

> **正在改版：** 试玩反馈认为 5 层关卡太像直线闯关，方向改为手工设计的开放“机关房间”。样板房间 The Escape Wheel 已可用 `--level=6` 进入：3 个销钉顺序不限，加入时钟门和借款评价。它通过试玩后，才会替换下面第 5 节的关卡。完整的 7+1 个房间设计和分步开发提示词见 [LEVELS.md](LEVELS.md)。

> **样板房间的已知疑点：** 脚本跑 6 种顺序时，用时差别明显（19 到 23 秒），借款却几乎相同（7.5 到 7.8 秒）。这说明顺序可能还不足以影响“3 秒怎么花”，脚本并非最优解，需要试玩确认。

## 1. 一句话

你握着能让整座钟楼停转的刹车，但每借走一秒，钟楼都要用两倍速讨回来。

**核心命题：你从来没有多得一秒，只是选择了何时面对将要到来的东西。**

这句话来自规则本身：冻结 N 帧、再还债 N 帧后，时钟走了 2N，和从未冻结完全相同。剧情的结尾也落在这句话上。

## 2. 规则

| 状态 | 按键 | 齿轮速度 | 债务 | 刹车 |
|---|---|---|---|---|
| NORMAL | 不按 | 1x | 0 | 可用 |
| FROZEN | 按住空格 | 0x，但碰到仍会死 | 每帧 +1，上限 180 帧（3 秒） | 使用中 |
| REPAYING | 松开，或到达上限被迫松开 | 2x | 每帧 -1 | 锁定 |

玩家移动速度在任何状态下都不变。

这一版新增两项：

- **落点幽灵：** 第 3 关起，有债务时显示每个齿轮在债务还清那一刻的位置，即 `时钟 + 2 × 债务`。按住时幽灵向前走，还债时幽灵不动。玩家不用心算，也能看到代价。
- **提前按键缓冲：** 还清前 8 帧内按下并一直按住，还清时立刻生效。被迫松开时一直按住的键不算，不会自动再次冻结。

## 3. 剧情

**背景：** 午夜，圣奥林钟楼。大钟失控，所有齿轮都在狂转。你是留在楼里的最后一名学徒，手里是工头留下的刹车。你要逐层上到主发条。

**讲述方式：** 只用每层开头的工头笔记，每段不超过 4 行，按 Enter 跳过，不做过场动画。玩家读到的内容就是下一关要用到的规则，同时也是工头的自白。

| 层 | 楼层 | 笔记揭示的内容 |
|---|---|---|
| 1 | The Undercroft | 钟楼失控，你拿到了刹车 |
| 2 | The Shafts | “刹车停住时钟，停不住齿。” |
| 3 | The Counting Room | “刹车不是礼物，是贷款。” |
| 4 | The Gallery | 工头借了三十年：没开走的渡船、走错门的医生。今晚全部到期 |
| 5 | The Mainspring | “你从没多得一秒。” 到发条那里，做我始终做不到的事 |
| 结局 | | 你松开了手。钟楼倍速走到天亮，敲完所欠的每一个钟点。工作台上留着工头的钥匙和一本标着“已还清”的账簿 |

全部文本都在 [`src/Game/Story.hs`](../src/Game/Story.hs)。如果比赛现场公布的主题不合适，只改这一个文件就能换故事，不影响规则。文本里不能用问号，字体没有这个字形。

## 4. 引导设计

原则：**教动作，不教解法。** 这样玩家是自己想通的，不是照着提示做完的。

| 层次 | 内容 | 何时出现 |
|---|---|---|
| 楼层笔记 | 规则和故事 | 每层开始前 |
| 玩家身边提示 | 只讲操作，如 `HOLD SPACE`、`LET GO OF SPACE` | 只在第 1 到 3 关 |
| 失败提示 | 解法方向 | 同一层死满 2 次后 |
| 死亡原因 | 按死亡时的状态解释 | 每次死亡 |
| 上限警告 | `CAP NEAR: LET GO` 和玩家身边的脉冲环 | 任何关，还剩 0.75 秒时 |

## 5. 关卡

每关只加一个新想法。完美通关全程约 35 秒，实际游玩时长要等试玩才知道。

| # | 楼层 | 新想法 | 玩家要想什么 | 冻结次数 | 峰值债务 |
|---|---|---|---|---|---|
| 1 | The Undercroft | 按住就能停 | 什么都不用想，学会按键 | 1 | 0.6 秒 |
| 2 | The Shafts | 停在路中间会挡路 | 该在哪里停住它 | 2 | 0.6 秒 |
| 3 | The Counting Room | 还债时刹车锁定 | 一次只够过一个竖井，什么时候松手 | 3 | 0.6 秒 |
| 4 | The Gallery | 走廊里只能借凹室让它过去 | 让齿轮停在凹室的哪一侧 | 2 | 1.7 秒 |
| 5 | The Mainspring | 同一个时钟管所有齿轮，并在路上还债 | 两个齿轮怎么同时算，3 秒怎么分配 | 2 | 2.3 秒 |

冻结次数和峰值债务来自脚本路线，不代表玩家的实际操作。

### 第 5 关为什么是结局

- 第一次冻结只为穿过竖井，这笔债只能**边走边还**，这时长齿轮正在 2 倍速运转。
- 第二次冻结有窗口限制：太早按下，3 秒走不到凹室，会被迫在走廊中间松手；太晚按下，齿轮已经越过凹室。
- 这一关同时用到前面所有东西：停的位置、锁定、幽灵、凹室和上限。

### 已验证的关卡性质

| 性质 | 结果 | 方法 |
|---|---|---|
| 每关都有可行路线 | 全部通过 | 脚本经真实规则回放 |
| 不用刹车能否过关 | 5 关都没找到路线 | 3 像素网格搜索，属有力证据，不是严格证明 |
| 第 3 关能否一次冻结过两个竖井 | 不能，任何时钟相位都最远到 x=-33，第二竖井出口在 x=38 | 冻结状态下做可达范围搜索 |
| 标记的安全区是否安全 | 全部安全 | 遍历完整齿轮周期 |
| 幽灵位置是否准确 | 还清时齿轮正好在幽灵位置 | 单元测试 |

## 6. 界面

- **去掉了：** 游戏中的大标题；占屏幕中央的大表盘，改成 HUD 里的小表盘。
- **移到玩家身边：** 操作提示、债务环、锁定标记、上限警告和还清时的绿色脉冲。
- **保留：** 每种状态都同时用颜色、图标和文字表示。

## 7. 还不知道的事

下面这些只有真人试玩才能回答，按依赖顺序排列：

1. 玩家能否看懂第 3 关的幽灵？它是帮助思考，还是让人分心？
2. 边走边还债是紧张，还是只让人觉得不公平？
3. 第 5 关的难度是否合适？它的窗口很窄。
4. 工头的故事有没有人读？

**试玩方法：** 找 3 到 5 个没玩过的人，运行下面的命令，全程不说话，记录他们在哪里停下、死了几次。结束后问开放式问题，比如“你在凹室里时在想什么”。

```bash
cabal run exe:escapement -- --log
```

可以用 `--no-ghost` 和 `--no-hints` 做对比，用 `--level=N` 直接跳到某一层。
